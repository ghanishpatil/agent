Solution

Step 1: Memory Dump Analysis
Received a 2GB memory dump file named dreamy_layers.raw. Started by checking file properties and scanning for embedded files.

$ ls -lh dreamy_layers.raw
-rw-r--r-- 1 user user 2.0G Mar 25 2026 dreamy_layers.raw

$ file dreamy_layers.raw
dreamy_layers.raw: data

Step 2: ZIP File Discovery
Scanned the memory dump for ZIP file signatures (PK\x03\x04) using a Python script:

with open('dreamy_layers.raw', 'rb') as f:
    data = f.read()
    pattern = b'PK\x03\x04'
    matches = [m.start() for m in re.finditer(pattern, data)]

Found valid ZIP file at offset 0x4190ab00

Step 3: ZIP Extraction
Extracted the ZIP file from memory by seeking to the offset and reading until the ZIP end signature:

with open('dreamy_layers.raw', 'rb') as f:
    f.seek(0x4190ab00)
    zip_data = f.read(1024 * 1024)
    end_sig = b'PK\x05\x06'
    end_pos = zip_data.find(end_sig)
    zip_data = zip_data[:end_pos + 22]
    
with open('extracted.zip', 'wb') as out:
    out.write(zip_data)

Step 4: Password Cracking
The extracted ZIP was password-protected. Used john with rockyou.txt wordlist:

$ zip2john extracted.zip > zip_hash.txt
$ john zip_hash.txt --wordlist=/usr/share/wordlists/rockyou.txt

Password found: gravity

Step 5: PCAP Extraction
Unzipped the file using the discovered password:

$ unzip -P 'gravity' extracted.zip
Archive:  extracted.zip
  inflating: challenge.pcap

$ ls -lh challenge.pcap
-rw-rw-r-- 1 user user 1404 Mar  8 13:30 challenge.pcap

Step 6: PCAP Analysis
Analyzed the PCAP file using tcpdump:

$ tcpdump -r challenge.pcap -A

Found ICMP echo request packets from 192.168.222.73 to 192.168.1.3 containing base64-encoded data in their payloads:

Packet 1: S2FhbHtDMDBQM1Ig
Packet 2: NVQ0WSBNM1NTNEcz
Packet 3: IEYwVU5EfQ==

Step 7: Base64 Decoding
Decoded the base64 strings from ICMP packets:

import base64

parts = [
    'S2FhbHtDMDBQM1Ig',
    'NVQ0WSBNM1NTNEcz',
    'IEYwVU5EfQ=='
]

combined = ''.join(parts)
flag = base64.b64decode(combined).decode()
