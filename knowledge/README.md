# knowledge/ — Structured index of historical CTF work

Generated by a **create-only audit** of this workspace. Nothing outside this folder was modified.
This folder unifies the scattered historical work (30 `writeups/` files, ~85 root solution docs,
3 competing meta-index docs, 60+ challenge dirs, 1,310 solver scripts) into three navigable views.

## Files
| File | Purpose |
|------|---------|
| `CHALLENGE_CATALOG.md` | Master list of every challenge found — by CTF event — with category, technique, flag, verification **status**, and the source document / directory. Start here. |
| `TECHNIQUE_INDEX.md` | **Tell → Attack → Example** lookup. Pattern-match a new challenge to a technique already used in this repo. |
| `WORKSPACE_AUDIT.md` | The audit itself: file inventory, the coverage-gap finding (only ~1/3 of solves are in `.kiro`), duplicate/competing knowledge, environment change (Docker removed), and non-destructive recommendations. |

## Key facts at a glance
- **~70 challenges** catalogued across **9+ events** (TDHT, CHAKRA, Kaalchakra, VishwaCTF, ctf7, K17, NNS, PwnSec, side).
- **~45 CONFIRMED** flags; ~12 CANDIDATE/per-instance; several documented UNSOLVED/failures.
- **Core gap:** most Kaalchakra + VishwaCTF + ctf7 + Chakravyuh-P2 solves live only in loose root
  docs and were never added to `.kiro/TRAINING_NOTES` or the `writeups/` folder.

## Trust discipline (important)
Flags here are **transcribed from existing docs, not re-verified in this audit.** Statuses:
`✅ CONFIRMED` (real extraction/accepted) · `⚠️ CANDIDATE` (guessed/ambiguous/per-instance) ·
`❌ UNSOLVED` · `🚫 DECOY` · `▫️ PLACEHOLDER`. Never submit a `⚠️`/`▫️` value without re-deriving it.

## Relationship to `.kiro/`
`.kiro/` remains the operating playbook (workflow, mistakes, technique deep-dives). This folder is a
**complementary index of what was actually done**. It intentionally does not alter `.kiro/`; the
audit only recommends backfilling the gaps it found (see `WORKSPACE_AUDIT.md` §8).
