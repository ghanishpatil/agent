# TimoPlayzzz OSINT Investigation

## Challenge Details
- **Category**: OSINT
- **Points**: 300
- **Difficulty**: Medium
- **Flag Format**: Kaal{}
- **Description**: "Hey guys, my friend is starting a gaming channel—go sub to @TimoPlayzzz on Youtube!"

## Target
- YouTube Channel: @TimoPlayzzz
- URL: https://www.youtube.com/@TimoPlayzzz

## Investigation Steps

### 1. YouTube Channel Analysis
Need to check:
- [ ] Channel About page
- [ ] Video titles and descriptions
- [ ] Video comments
- [ ] Community posts
- [ ] Channel banner/profile picture
- [ ] Social media links in description
- [ ] Playlists
- [ ] Channel creation date
- [ ] Subscriber count

### 2. Common OSINT Techniques for YouTube
- Check video metadata
- Look for hidden messages in:
  - Video descriptions
  - Video titles
  - Comments (especially pinned comments)
  - Channel description
  - About section
- Check for social media links (Twitter, Instagram, Discord, etc.)
- Look for patterns in upload times
- Check for steganography in thumbnails
- Look at video transcripts/captions

### 3. External Resources
- Google cache of the channel
- Wayback Machine (archive.org)
- Social media search for "TimoPlayzzz"
- Reddit mentions
- Discord servers

### 4. Flag Locations (Common in OSINT CTFs)
- Hidden in video description
- In comments (by channel owner)
- In channel About section
- In social media bio linked from channel
- In video itself (visual or audio steganography)
- In channel banner image
- In profile picture
